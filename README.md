# 🧁 Frost & Flour — Artisan Bakery

A modern artisan bakery ordering website built with React + Vite.

## Features
- Browse menu by category (Breads, Pastries, Muffins, Cakes, Beverages)
- Add to cart with quantity controls
- 3-step checkout: Address → UPI / Cash on Delivery → Confirmation
- Saved addresses + new address form with validation
- Responsive navy & beige luxury UI
- Smooth animations and marquee

## Tech Stack
- React 18
- Vite
- CSS3 with custom properties

## Getting Started
npm install
npm run dev
